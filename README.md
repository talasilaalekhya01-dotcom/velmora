# Velmora — Your cycle. Your clarity.

> **Tagline:** Your cycle. Your clarity.  
> **Welcome Headline:** Understand your cycle. Feel more informed.

Velmora is a privacy-first, responsive menstrual health and wellness web application built with HTML5, CSS3, and modern modular ES modules. It stores all records directly on the user's device using browser IndexedDB, requiring no accounts, no cloud sync, and no third-party health tracking databases.

---

## 1. Core Principles & Privacy Commitment

1. **Local-First Architecture:** All period dates, flow intensities, 0–10 pain levels, symptoms, custom notes, and practitioner reviews are stored strictly in client-side **IndexedDB**.
2. **No Accounts or Remote Databases:** No email addresses, phone numbers, or passwords are collected. Data never leaves the user's browser.
3. **Transparent Estimations:** Predictions are statistical estimates computed using the median of recorded start intervals. Predictions are never presented as guaranteed biological certainties. Velmora **never confirms pregnancy or ovulation**, and **never labels days as safe for contraception**.
4. **Informational Clinical Guidance:** Health alerts are generated by a transparent JavaScript rule engine grounded in ACOG (*American College of Obstetricians and Gynecologists*) and NHS clinical criteria. They are informational tools to prepare users for medical consultations, not automated diagnoses.
5. **Zero-Tracking Map Searches:** Location searches via OpenStreetMap (Nominatim and Overpass) send only city names or geographic coordinates. Menstrual cycle data and personal health logs are never sent to external servers.

## 2. Application Architecture & The 10 Connected Sections

1. **Dashboard:**
   - Visual cycle day indicator (e.g. Day 14 of ~28 days).
   - Estimated next period start date and countdown.
   - Quick action strip (*Log Today*, *Start Period*, *Open Calendar*, *Cycle Insights*, *Find Care*).
   - Overview of today's flow, pain rating, symptoms, and mood.
   - Prominent notification ribbon for active health alerts.
   - Empty state guidance when no periods are recorded yet.

2. **Period Calendar:**
   - Month-by-month navigation with "Today" quick-jump.
   - Clear visual legend for recorded periods, estimated upcoming periods, today, selected dates, and logged symptoms (using shape and styling, not color alone).
   - Create, edit, and delete period records with start dates and optional end dates.
   - Validation against overlapping records, start dates in the future, and end dates preceding start dates.
   - Selected-day inspector with one-click access to daily health logs.

3. **Daily Health Log:**
   - Menstrual flow level selector (*None*, *Light*, *Medium*, *Heavy*), distinguishing unrecorded from explicitly recorded "none".
   - Pain intensity slider (0–10 scale) with clinical reference markers (*0: None*, *1–3: Mild*, *4–6: Moderate*, *7–9: Severe*, *10: Disabling*).
   - Multi-select common symptoms (*cramps*, *headache*, *bloating*, *fatigue*, *nausea*, *back pain*, *breast tenderness*, *acne*, *mood swings*, etc.) plus an **instant custom symptom creator**.
   - Mood selector (*calm*, *happy*, *energetic*, *sensitive*, *anxious*, *irritable*, *sad*, *fatigued*).
   - Medications and relief observations (e.g. heating pad, ibuprofen).
   - Detailed personal wellness notes.
   - Instant database confirmation upon saving.

4. **Cycle Insights:**
   - Interactive Chart.js charts:
     - **Cycle Lengths Over Time:** Consecutive start-to-start intervals with median reference baseline.
     - **Period Bleeding Durations:** Days of bleeding recorded per period.
     - **Pain Intensity Trend:** 0–10 pain scores plotted chronologically across logs.
     - **Top Symptoms Frequency:** Horizontal distribution of most frequent physical sensations.
   - Transparent explanation of median vs. mean and sample-size indicators (*preliminary baseline* if < 3 completed cycles).

5. **Health Alerts:**
   - Transparent JavaScript rule engine evaluating:
     - *Extended Bleeding:* Bleeding lasting 8 or more days (ACOG/NHS criteria).
     - *Consecutive Heavy Bleeding:* Heavy flow recorded for 3+ consecutive days.
     - *Severe Pain Entries:* Pain levels ≥ 8/10 recorded on multiple days.
     - *Short / Long Intervals:* Intervals under 21 days or over 38 days.
     - *Marked Personal Variation:* Swings of 8+ days compared to personal median.
   - Each alert displays what was recorded, dates, clinical rationale, recommended next steps, and dismiss controls.
   - Independent Urgent Care warning signs accessible at all times.

6. **Find Doctors & Clinics:**
   - Interactive Leaflet map with OpenStreetMap tiles.
   - Facility search by city, town, or postal code via Nominatim geocoder.
   - Device geolocation button (only invoked with explicit user browser permission).
   - Overpass API integration querying clinics, hospitals, and confirmed gynecological practices.
   - Resilient offline directory fallback ensuring maps and facility details always work.
   - Private personal clinic reviews and 1–5 star ratings stored in IndexedDB.

7. **Period Products:**
   - Objective, unbiased guides covering: *Disposable Sanitary Pads*, *Reusable Cloth Pads*, *Tampons*, *Menstrual Cups*, *Menstrual Discs*, and *Period Underwear*.
   - Sourced details on wear times, Toxic Shock Syndrome (TSS) risk levels, ecological footprints, pros, cons, and cleaning/disposal.
   - Personal review system allowing users to record comfort, leak protection, and personal verdicts (*Regular choice*, *Backup option*, *Not for me*, *Want to try*).
   - Zero e-commerce or sponsored product links.

8. **Health Reports:**
   - Customizable timeframes (*Last 30 Days*, *3 Months*, *6 Months*, *1 Year*, or custom date ranges).
   - Granular inclusion toggles (*Personal notes*, *Medications*, *Health alerts*).
   - Live formatted preview.
   - One-click exports:
     - **Print / Save as PDF:** Clean `@media print` layout hiding app navigation and buttons.
     - **Markdown (`.md`):** Formatted text document with structured summary tables.
     - **Standalone HTML (`.html`):** Self-contained styled report file.

9. **Health Education:**
   - Evidence-based articles grounded in clinical guidelines from ACOG, NHS, CDC, and WHO:
     - *Understanding Menstrual Cycle Phases & Hormonal Shifts*
     - *Period Pain & Symptoms: What Is Typical vs. When to Seek Care*
     - *Menstrual Hygiene, Product Safety & Toxic Shock Syndrome Facts*
     - *Prediction Algorithms: Scientific Limitations & Why Estimates Vary*
     - *Preparing for Your Healthcare Appointment: Practical Tips*
     - *Local-First Health Tracking: Why Your Data Stays on Your Device*
   - Honest review date: **October 2026** with genuine citation links.

10. **Settings & Privacy:**
    - Cycle preferences (default cycle length, period duration, luteal phase length).
    - Optional Web Crypto PIN protection using **PBKDF2 with 100,000 iterations**, SHA-256, and random salt.
    - Notification preferences (discreet period reminders and daily check-in alarms).
    - **Demonstration Mode:** Load a realistic 4-month sample dataset with 1 click, and clear it anytime.
    - **Backup & Restore:** Full offline JSON data export and import.
    - **Complete Reset:** Confirmed permanent purge of local IndexedDB records.

## 3. Technology Stack & Standards

- **Core:** HTML5, CSS3, Modern TypeScript / JavaScript (ES Modules).
- **Storage:** HTML5 IndexedDB API (`velmora_menstrual_health_db`).
- **Data Visualization:** Chart.js 4.
- **Mapping:** Leaflet 1.9 with OpenStreetMap tile servers & Overpass QL.
- **Cryptography:** Web Crypto API (`crypto.subtle.deriveBits` with PBKDF2).
- **PWA & Offline:** Web App Manifest (`manifest.json`), Service Worker (`sw.js`), Cache-First & Stale-While-Revalidate caching strategies, in-app install prompt.
- **Styling:** Tailwind CSS with custom Velmora brand palette:
  - Page Background: `#FFF0F5`
  - Soft Pink Surfaces: `#F8C8DC`
  - Subtle Borders: `#F1D5D8`
  - Highlights: `#FFB6C1`
  - Watermelon Accents: `#FB6F92`
  - Primary Action / Prominent Buttons: `#A4365A`
  - Text & Headings: `#392332`
  - Secondary Text: `#725B69`

## 4. Local Development Instructions (VS Code & Local Server)

### Prerequisites
- Node.js (v18 or newer)
- npm or bun

### Step 1: Clone or Open Project
Open the project directory in VS Code:
```bash
code .
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Run the Development Server
```bash
npm run dev
```
Open your browser to `http://localhost:3000`.

### Step 4: Build for Production
To create a production bundle:
```bash
npm run build
```
The optimized static output is generated in the `/dist` directory.

## 5. Deployment Instructions (Vercel Static Hosting)

Velmora is completely client-side and requires zero server runtimes or backend databases, making it 100% compatible with static hosting on **Vercel**, **GitHub Pages**, **Netlify**, or **Cloudflare Pages**.

### Deploying to Vercel via CLI:
1. Install Vercel CLI:
   ```bash
   npm i -g vercel
   ```
2. Deploy:
   ```bash
   vercel
   ```
   Accept default settings:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`

### Deploying via Vercel Git Integration:
1. Push your repository to GitHub or GitLab.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your repository.
4. Set Build Command: `npm run build` and Output Directory: `dist`.
5. Click **Deploy**.

## 7. Known Limitations & Technical Notes

1. **Browser Clearing:** Because records are stored purely client-side in IndexedDB, clearing site cookies and storage in the browser will clear local records. Users should use the **Export JSON** option in Settings to save personal offline backups.
2. **Background Push Notifications:** Browser notification scheduling in static web apps depends on the browser being active. Mobile operating systems (such as iOS Safari) restrict background timers unless the PWA is installed to the home screen.
3. **Overpass API Rate Limits:** Public OpenStreetMap Overpass servers occasionally throttle high-frequency requests; Velmora includes a built-in regional directory to ensure facility listings never fail to render.
4. **Non-Medical Nature:** Velmora is an observational health log. It does not replace professional clinical evaluation, diagnostic ultrasound, or medical advice.
